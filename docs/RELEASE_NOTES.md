**Minecraft 26.1.2 / NeoForge 26.1.2.75 / Java 25，仅客户端安装。**

使用 `postmark-26.1.2-0.1.2.jar` 替换旧版，保留实例内 `postmark` 数据目录。

导入玩家确认的 74 个展馆、112 枚章，作为剪影数量和集齐判断的目标。36 个单章馆显示一个剪影，38 个双章馆显示两个；预设不提供章面或玩家进度。实地发现后显示未点亮章面，实际领取后点亮，领取齐已知目标即可打勾，不必等周边完整扫描。

已加载区块及传送点周边 64 格的扫描继续运行。清单外新增章会自动补回并重新判断集齐；确认目标中的已知章位不会因局部扫描未发现而消失。清空重收集与 `/postmark export` 保持支持。
