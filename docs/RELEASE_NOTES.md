Postmark · 旅途来信 — 0.1.0-alpha.23（预发布）。

**Minecraft 26.1.2 / NeoForge 26.1.2.75 / Java 25，仅客户端安装。**

使用 `postmark-26.1.2-0.1.0-alpha.23.jar` 替换旧版，保留实例内 `postmark` 数据目录。

以展馆主世界传送点为中心，水平 X/Z 各向外 64 格范围的区块全部加载且实际扫完后，按本地搜索结果消除未发现的未知章位。只有一枚章时去掉问号，实际领取后显示圆勾；没有发现章时去掉问号，但不盖集齐勾。

未加载的区块不会提前算作扫描完，旧的零散检索记录不会直接升级为范围确认。判断结果随本地记录保存，传送点位置变化后需要重扫。玩家清单明确存在、以及历史已发现的章继续保留；后来发现未领取章时撤销圆勾。

这是以传送点周边为依据的本地估计，不能保证远处或特殊空间没有其他章。详情标注「周边64格已检索」或「本地搜索已集齐」。右下检索标识换成两枚大小、方向和墨色不同的像素猫爪印，点击可查看检索结果。

集齐圆勾放在馆图上方，与待检索问号共用状态贴签位置；确认检索且集齐后换成绿勾。馆图外缘加绿色细框，图片保持完整。点击绿勾可查看详情。
