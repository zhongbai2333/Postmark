Postmark · 旅途来信 — 0.1.0-alpha.25（预发布）。

**Minecraft 26.1.2 / NeoForge 26.1.2.75 / Java 25，仅客户端安装。**

使用 `postmark-26.1.2-0.1.0-alpha.25.jar` 替换旧版，保留实例内 `postmark` 数据目录。

背包里的漫游志入口可以直接用左键拖到空闲位置，轻点仍然打开。位置会保存，生存与创造背包共用；窗口大小或 GUI 缩放变化时按屏幕比例定位并保持在屏幕内。拖动不会误操作下方槽位。

关闭漫游志后重新打开，会恢复上次的缩放和浏览中心。视图按服务器/世界及玩家分别保存，重启后仍能恢复，调整窗口大小也会保留浏览中心。

缩小全览时，章状态与装饰使用缓存，印章预览分批生成；低于 55% 时优先显示已有预览，未加载的章暂用木柄/金柄轮廓，悬停或放大后补充细节。馆图与收藏状态保持显示。

放大后的纸片白边和旋转猫爪边缘可点击。背景纸纹铺满整个浏览区域，向四周延伸，拖动内容仍有范围限制。

明信片收藏册保留原有双页、书脊、卡片尺寸与排列，只替换书页里面的纯色底纸：浅金底，每页中央淡金 TeaCon 标记，下方显示当前 Minecraft 玩家名。底纹在明信片下层，翻页、选择和删除操作不变。
