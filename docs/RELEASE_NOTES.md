Postmark · 旅途来信 — 集章吊牌与鼠标操作。

**Minecraft 26.1.2 / NeoForge 26.1.2.75 / Java 25，仅客户端安装。**

下载 `postmark-26.1.2-0.1.0-alpha.10.jar` 放入 `mods`，移除旧版 Postmark JAR，保留实例内的 postmark 数据目录。`-sources.jar` 无需安装。

- 可翻面的集章吊牌：普通、大师、展馆统计与十孔卡，每十枚解锁像素纪念票，可以放到明信片上保存。
- 详细说明集中到底部鼠标悬停提示，界面保留简短名称与数字。
- 新建、恢复素纸、打开目录、关闭、签名撤回和清空均有可点击控件，快捷键继续可用。

统计来自本地已收藏的不同 SMU 章；不把预设章、重复盖印或纪念票计入，不推算全服总章数。

22 项单元测试、121 枚章的游戏回归及新增鼠标/纪念票流程通过。SMU 1.1.12 集成服务器验证沿用 alpha.8，联动代码未变。远程活动服与特殊资源包仍需实际验证。
