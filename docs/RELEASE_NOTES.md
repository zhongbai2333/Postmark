Postmark · 旅途来信 — 首次 MIT 开源发布。

**环境：Minecraft 26.1.2 / NeoForge 26.1.2.75 / Java 25。仅安装在客户端。**

下载 `postmark-26.1.2-0.1.0-alpha.9.jar` 放入 `mods` 文件夹，进入世界按 P 打开。`-sources.jar` 为源码包，无需安装。

支持像素明信片、蜂窝章袋与展区搜索、实体印章与橡皮、大小/角度调整、半透明落点预览、信封动画和鼠标签名。本地导出明信片及签名信封两张 PNG，成功后打开文件夹并自动换新卡。可选联动 SignMeUp / ExhibitionPortal 1.1.12。

此版本修复大袋取章后左侧未定位和归位突然消失，删除袋口折线并居中搭扣三点。

本地验证：19 项单元测试、121 枚章的实际游戏回归通过；SMU 1.1.12 集成服务器验证通过（alpha.8，alpha.9 联动逻辑未变）。当前为 alpha，远程活动服和特殊资源包仍需实际验证。
