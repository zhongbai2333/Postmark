Postmark · 旅途来信 — 0.1.1（正式版）。

**Minecraft 26.1.2 / NeoForge 26.1.2.75 / Java 25，仅客户端安装。**

使用 `postmark-26.1.2-0.1.1.jar` 替换旧版 JAR，保留游戏实例内 `postmark` 数据目录。

修复 SMU 清空收藏后 Postmark 仍显示已解锁的问题。执行 SMU 1.1.12 的 `/teacon exhibition debug clear_footprint` 后，章袋、数量统计和漫游志的已收集状态会跟随服务器撤销；重新领取后逐枚解锁。

已有明信片、签名、落纸印迹和图片资源保留。本地盖章台发现、检索猫爪及范围记录也保留，未领取的章仍可作为攻略线索显示。

清空前尚未完成的章面加载不会重新加回旧收藏，鼠标上拿着或尚未落纸的失效印章会取消。

新增客户端命令 **`/postmark export`**，无需 OP。收集完后执行，点击聊天中的“打开导出文件夹”，把 `stamp-catalog-…json` 分享给维护者即可用于更新内置清单。文件包含展馆 UUID、名称、服务器已领取章、仅在附近发现的章及本地检索/集齐状态，不包含玩家 ID、服务器地址或私人图片；未出现的章不自动判定为不存在。
