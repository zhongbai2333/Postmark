Postmark · 旅途来信 — 0.1.3（正式版）。

**Minecraft 26.1.2 / NeoForge 26.1.2.75 / Java 25，仅客户端安装。**

使用 `postmark-26.1.2-0.1.3.jar` 替换旧版，保留实例内 `postmark` 数据目录。

修复同一展馆内两枚 `visitor` 使用不同图案时，后一枚覆盖前一枚的问题。扫描、收藏、计数和导出均按展馆、章 ID 与图案区分；两枚普通章可分别显示在漫游志左右角并单独拿取，领齐所有已知图案才会打勾。同 ID、同图案的重复盖章台仍只算一枚。

SMU 同一章 ID 的服务器记录仍只保存最后一枚，Postmark 在本地保留此前领过的其他图案。服务器清空该章位时，本地所有对应图案一并撤销；已有明信片和检索记录保留。`/postmark export` 会区分当前服务器记录、本地保留的已领取图案和仅发现图案。

旧版收藏按保存的章面匹配迁移。已经被覆盖、且没有本地记录的图案，需要再次领取一次。

验证：72 项单元测试通过；SMU 1.1.12 集成测试覆盖两枚普通章的独立领取、左右拿取、集齐判断、清空重收集、保存恢复、导出及地图自动盖印。
