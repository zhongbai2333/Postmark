Postmark · 旅途来信 — 原图明信片与自适应信封。

**Minecraft 26.1.2 / NeoForge 26.1.2.75 / Java 25，仅客户端安装。**

下载 `postmark-26.1.2-0.1.0-alpha.11.jar`，替换 `mods` 中的旧 Postmark JAR；保留实例内 postmark 数据目录。`-sources.jar` 无需安装。

- 拖入底图后，点击「裁切」或「原图比例」的效果预览；可用 × 取消。
- 裁切采用 3:2 居中裁切；原图模式完整保留画面，信纸、盖章、擦除和翻页按比例适应。
- 信封角、装封、封口、翻面签名与寄出跟随底图比例，竖图使用竖版信封。
- 正面和签名信封按相同比例导出，原图模式长边 1800；旧草稿保持标准比例。

26 项单元测试及实际游戏回归通过，包含原图/裁切选择、取消、竖纸盖章擦除、自适应信封签名、900 × 1800 双面 PNG、混合比例翻页和原有 121 枚章测试。自由调整裁切区域尚未实现。
