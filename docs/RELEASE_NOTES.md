Postmark · 旅途来信 — 像素对齐与明信片收集册。

**Minecraft 26.1.2 / NeoForge 26.1.2.75 / Java 25，仅客户端安装。**

下载 `postmark-26.1.2-0.1.0-alpha.12.jar` 替换旧版 Postmark JAR，保留实例内 postmark 数据目录。`-sources.jar` 无需安装。

- 修复虚影与实际印迹的一像素偏移，统一文档落印和纸面像素坐标。
- 点击右上角的大册子图标查看全部明信片：左右各四张，一屏八张，页角箭头翻页。
- 点击缩略图打开，每张卡旁的垃圾桶可删除；勾确认，× 取消。删空末页自动回前页，删除最后一张留下新空白纸。
- 已导出的图片、共用资源和印章收藏保留。

验证：28 项单元测试；六组真实 GPU 虚影/实际着墨轮廓比较为零差异；19 张卡的收集册分页、选择、删除与持久化检查通过。
