Postmark · 旅途来信 — 0.1.0-alpha.27（预发布）。

**Minecraft 26.1.2 / NeoForge 26.1.2.75 / Java 25，仅客户端安装。**

使用 `postmark-26.1.2-0.1.0-alpha.27.jar` 替换旧版，保留实例内 `postmark` 数据目录。

修复只有大师章的展馆仍持续寻找普通章的问题。传送点周边 X/Z ±64 格的全部区块完成检索后，以实地发现和已领取记录为准，隐藏仅来自预设的多余章位；单普通章、单大师章和零章统一处理。未完成范围检索仍保留预设提示。

发现但未领取不会标记集齐，零章馆不盖勾；以后发现新章会补回章位并重新判断集齐。已有完整范围记录会直接应用新规则，不需要清空数据。
