Postmark · 旅途来信 — 0.1.0-alpha.18《漫游志》（本地试用构建，尚未发布）。

**Minecraft 26.1.2 / NeoForge 26.1.2.75 / Java 25，仅客户端安装。**

使用本地构建的 `postmark-26.1.2-0.1.0-alpha.18.jar` 替换旧版 Postmark JAR，保留实例内 postmark 数据目录。

点击章袋旁或背包物品栏旁的拼贴纸页打开导览。所有展馆在一张大纸面上自由散布，拖动平移，滚轮或右侧加减按钮平滑缩放，四角框按钮查看全部；悬停纸片放大，背景有淡色像素山形、树木和水纹。从背包进入后，右侧印章图标可打开盖章工作台并返回导览。

两角章采用木柄普通章、金柄大师章的实体造型，未获得为淡色虚影；点击馆图传送、馆名看介绍、已获得章拿取盖印，拖动画布不会误触传送。

附近检索实际完成后才留下脚印，抵达或 SMU 已到访标记不会代替检索。发现与已获得分开，扫描不会授章。内置玩家表的 71 条记录，其中 66 条按官方 UUID 匹配；5 条合并或未核实身份的记录待核对。清单中的章提前显示淡色问号章位，实际扫描与收藏补图。明确单章的馆可在领取后按清单打勾，空白和存疑仍未知，新增未领取章会撤销圆勾。见 STAMP_CATALOG.md。

46 项单元测试，以及真实 SMU 集成服务器内的导览和原盖章联动验证；详细证据与尚未覆盖范围见 VALIDATION.md。测试展馆与图标是夹具，正式 JAR 不包含它们或 SMU 本身。
