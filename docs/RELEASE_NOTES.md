Postmark · 旅途来信 — 0.1.4（正式版）。

**Minecraft 26.1.2 / NeoForge 26.1.2.75 / Java 25，仅客户端安装。**

使用 `postmark-26.1.2-0.1.4.jar` 替换旧版，保留实例内 `postmark` 数据目录。

- 修复锻星砧等大型 GUI 模型无法收录：完整捕获原始章面，并保留失败原因提示。
- 新章落印、墨圈扩散、收入章袋。Shift 获取时留在世界中自动入库，把动画存到本地；下次打开盖章界面，一批新章排开后一起入袋。重复领取不重复播放，播完才移出队列。
- 已收藏盖章台在悬浮图标和台面显示绿色勾。相同展馆、相同章 ID 与 item 的重复台子只算一枚，所有副本共享状态；同 ID 不同图案分别收集。
- 漫游志提供全部、未收集、未逛过筛选，可搜索展馆名称和关联 Mod；当前可见的新收藏章按顺序点亮，已完成的动画记录会保存。
- 锻星之旅预设包含时空超算和锻星砧两枚普通章，共 74 个馆、113 枚预期图案。未发现只显示剪影，实地发现后显示淡色章面，获得后点亮；扫描继续补充新章。

SMU 清空章位后，对应本地收藏、勾标识和待播放记录一并撤销，已有明信片与检索记录保留。

验证：88 项单元测试通过；真实 SMU 集成、漫游志全流程及未安装 SMU 的收藏册游戏回归通过。大型章面使用固定官方模型资源的测试别名验证，未运行完整 AnvilCraft 整合包或正式活动服务器。
