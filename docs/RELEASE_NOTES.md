Postmark · 旅途来信 — 0.1.0，首个正式版。

**Minecraft 26.1.2 / NeoForge 26.1.2.75 / Java 25，仅客户端安装。**

下载 `postmark-26.1.2-0.1.0.jar` 放入客户端 `mods` 文件夹，替换旧版 JAR；不要安装 `-sources.jar`。保留实例内的 `postmark` 数据目录，原有草稿、收藏和检索记录可直接沿用。进入世界后按 **P** 打开明信片。

- 从蜂窝章袋取章、调整大小与旋转、重复盖印；支持展馆名搜索和擦除。
- 导入照片制作明信片，装入信封、鼠标手写签名，导出明信片和信封两张 PNG。
- 双页收藏册保存和浏览卡片，左右底纸各有 TeaCon 水印和玩家 ID。
- 《漫游志》以拼贴画布展示 SMU 展馆，支持鼠标缩放、拖动、展馆传送、检索与集齐标识；背包入口位置和浏览视图会保存。
- 扫描客户端已加载区块内的盖章台；传送点周边 X/Z ±64 格完整检索后，支持普通单章、大师单章和零章馆。实地结果覆盖多余预设，后来发现新章会补回并重新判断集齐。

正式版功能与 alpha.27 一致，包含圆勾渲染修复及大师单章判定修复。SMU 联动已验证 ExhibitionPortal 1.1.12；没有 SMU 也可使用内置“启程”章制作明信片。

构建和 60 项单元测试通过，沿用 alpha.27 已通过的实际 Minecraft / SMU 合成世界回归记录。完整记录见仓库 `docs/VALIDATION.md`。
