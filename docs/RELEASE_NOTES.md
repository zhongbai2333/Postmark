Postmark · 旅途来信 — 0.1.0-alpha.20（本地试用构建）。

**Minecraft 26.1.2 / NeoForge 26.1.2.75 / Java 25，仅客户端安装。**

使用 `postmark-26.1.2-0.1.0-alpha.20.jar` 替换旧版 Postmark，保留实例内 `postmark` 数据目录。

自动发现章的范围从玩家周围 32 格扩大到客户端所有已加载区块。走动不再中断扫描；每 tick 最多检查 4 个区块，批量保存结果并重复检查后来新增或改变的盖章台。已卸载的区块会跳过，不会主动加载远处区块。

未检索展馆上方统一显示问号，玩家预设不会提前消除问号。扫描后仍有未知章位时继续保留；实际发现或清单明确无该章位后才消除未知，空检索不会删除真实未领取章。

右下脚印放大为浅底深色双脚印贴章，集齐后也保留。问号和脚印均可悬停查看提示、点击打开详情。

发现仍与领取分开，不会自动授章。漫游志、玩家预设清单、传送和盖章功能继续保留。

验证记录见 [VALIDATION.md](VALIDATION.md)。
