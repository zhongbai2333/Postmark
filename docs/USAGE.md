# 操作说明

## 信纸与工具

按 P 打开明信片。可以从左侧腰包拖章到纸上松开，也可以点击取章，再点击纸面盖下。同一个章可以重复使用；已盖印迹的位置与大小固定，想调整时先擦除再盖。

持章按住右键拖动：向右或向上放大，反向缩小，范围为纸宽的 2%–50%。缩放时落点固定，松开右键仍拿着章；左键确认盖印。每次重新拿章从默认大小开始。滚轮旋转；持章停稳 500 ms 后，工具变为半透明并出现实际章面预览，此后移动、旋转仍保持，下一次拿章才重置。

盖完自动归位，纸外松开或 Esc 取消。上一枚回包时可以拿另一枚。从大袋拿章后，左侧腰包自动平滑滚动到对应格子；归位跟随真实章位。远距离滚动未完成时会延长回包动画。

点击纸张左下橡皮或按 E 拿起橡皮，点击印迹擦掉最上层。拿着橡皮时点击章，自动放回橡皮并拿章。

## 搜索章袋

点击左侧搭扣或按 Tab 展开。章面错位排列，悬停放大并显示展区名称；其他章不被挤动。滚轮平滑缩放，拖动空隙或按住右键平移。

在袋口输入展区名称，匹配章从原位置浮到前面，其余章留在暗处。名称与类型可以组合，例如 `花园 大师`；也支持 `expert`、`visitor` 及 ID，英文大小写不敏感。多个空格分隔的词需同时匹配。目前不支持拼音搜索。

只有普通章或大师章时，只显示已有的一枚；没有匹配章时提示未找到。仅凭收藏无法区分展区没有设置章与玩家尚未收集。不同展馆可以共用图片，章的身份仍独立。搜索结果很多时滚轮上下浏览。

点击结果后收袋并拿起该章，移动到纸面再点击；也可以直接拖出后松开盖印。清除文字回到章堆，右上 ×、Esc 或 Tab 收起。在同一界面内保留搜索和浏览位置。

## 集章吊牌与纪念票

左下吊牌正面显示已收集的不同章数；点击翻面，查看普通、大师、展馆数量和十孔卡。每收集十枚，解锁一张带数字的纪念票，点击拿起后放到明信片上，也可缩放、旋转和擦除。两侧小箭头切换已解锁的票。

重复盖印、启程预设章和纪念票不增加收藏数。同一展馆的不同章分别计数，展馆只计一次。孔卡目标是下一个十枚里程碑，不代表全服总数。SMU 会同步全部登记展馆及玩家已获得的章；未获得的章由内置玩家清单预告，并通过《漫游志》检查客户端已加载区块内的盖章台补充。纪念票随本地收藏保留。

## 漫游志

点击章袋旁或背包物品栏旁的拼贴纸页。全部展馆散落在同一张大纸面上，不再按左右面分栏或翻页。按住左键拖动纸面或馆图即可平移，滚轮围绕鼠标位置平滑缩放；右侧「+」「−」也能缩放，四角框按钮显示全部展馆。初始比例方便阅读，缩小后可看全局，悬停纸片会平滑放大。

从背包打开时，右侧另有实体印章图标，点击进入盖章工作台，关闭工作台返回原导览视图。角上的章也采用实体印章造型：木柄代表普通，金柄代表大师；已获得显示完整颜色，清单预告或已发现但未获得显示淡色虚影，完全未知仍留空。

- 背包里的漫游志入口：左键点击打开，按住拖动调整位置，松开保存。生存和创造背包共用位置，GUI 缩放后按屏幕比例定位；可移到 JEI 或药水效果以外的空闲区域。
- 重开漫游志恢复上次的缩放和浏览中心，窗口调整时保留中心。入口位置保存在实例内 `postmark/guide-entry-position.json`，每个服务器/世界及玩家的视图保存在其数据目录的 `guide-view.json`。
- 背景纸纹连续铺满浏览区域，不显示整张纸的边缘；展馆内容仍有拖动范围。悬停放大后的纸片白边同样可点击。
- 点击馆图：通过 SMU 原协议传送到展馆；未设置有效传送点时保留界面并提示。
- 点击馆名：查看介绍与已知印章。传送按钮和关闭控件支持鼠标。
- 左上为普通章，右上为大师章。预设已知但未发现图案时显示问号章，完全未知时留空，发现但未获得时显示淡色实体章虚影，已获得时显示完整实体章。点击已获得的章会回到明信片并拿起它；不会凭扫描结果授章。
- 非普通/大师的章通过小「+数量」入口查看，不会被挤掉或忽略。
- 脚印表示在附近完成过一次检索。SMU 的已到访标记、打开手册、发送传送请求和单纯抵达都不产生脚印。扫描在后台自动进行，无需点击扫描按钮。
- 展馆上方的问号贴签表示章位尚未检索或仍有未知。未检索的馆统一显示问号，玩家预设或已收藏章不会直接替代扫描。点击问号查看详情。
- 右下错落的猫爪印贴章表示已做过区块检索，点击可看结果；集齐后也保留。问号与脚印同时存在表示已检索但仍有章位未确认。
- 单个区块空扫描仍保留未知。以主世界传送点为中心，水平 X/Z 各向外 64 格范围内的区块都加载、实际扫完后，会按本地搜索结果消除未发现的未知章位。只找到一枚章时可去掉问号，领取后显示圆勾；未发现任何章时去掉问号但不盖集齐勾。
- 清单明确存在或此前已发现的章不会被空扫描删除。传送点变化会要求重新检索；后来发现额外未领取章时撤销圆勾。这个范围判断不保证展馆远处或特殊空间里没有其他章。
- 馆图外缘的绿色细框表示清单中已明确的章位及已发现章均已获得；没有预设时要求普通、大师均已获得。明确单章的馆可完成，空白或零散空检索不会当作没有另一枚章，完成传送点周边范围后可按本地结果判断；新发现未获得的额外章会撤下集齐标识。检索确认后，馆图上方的问号换为浅底深绿圆勾，点击可查看详情；馆图本身不被圆勾遮挡。

检索分批检查客户端所有已经加载的区块，不再限制玩家周围 32 格，走动不会打断检索；已卸载的区块会跳过，不请求远处区块，不代表全馆穷尽搜索。记录保存在当前服务器/世界与玩家目录下的 `travel-journal.json`，与明信片草稿分开；未安装 SMU 时可以打开刊物，但没有展馆目录。

界面只保留名称、数字和短状态。把鼠标移到物件上，在屏幕最下方查看操作说明；按钮上的键名只提示可选快捷键。

## 翻页、照片与签名

- 左右淡色像素箭头或 [ / ] 切换已有卡片，点击纸上方带加号的纸张新建（也可 N）；每张卡独立保存照片、印迹和签名。
- 将 PNG/JPG 拖到界面后，点击「裁切」或「原图比例」预览确认。裁切居中填满 3:2 信纸；原图模式完整保留画面，按原比例盖章，章面保持正方形。× 或 Esc 取消导入。点击纸上方素纸控件恢复标准 3:2 信纸（也可 B）。
- 点击右下信封角，信纸装入信封并封口，随后翻面。信封与底图比例一致，竖图使用竖版信封；签名区域和寄出动画也随之调整。
- 在背面按住左键签名；每笔松开后保存。点击信封左侧回转箭头撤回上一笔、橡皮清空签名（也可 Ctrl+Z / Delete），Esc 或左下纸角返回明信片。
- 点击右下封蜡，保存后寄出。签名可以留白。

## 明信片收集册

点击加号右侧的大册子图标打开册子。左右两页各四张，一屏八张；缩略图保留原卡比例。页角箭头翻页，点击缩略图取出该卡。再次打开时定位当前卡所在的页。

每张卡旁的小垃圾桶用于删除，点击后用勾确认、× 取消。删除当前卡自动选相邻卡；最后一页删空后回到前页。删除最后一张时留下新空白信纸。删除只移除收集册草稿，已导出的本地图片、共用图像资源与印章收藏均保留。

## 导出与草稿

每次导出包含 `front.png` 和 `envelope.png`。标准/裁切模式为 1800 × 1200；原图模式长边 1800，短边按原图比例取整（如 1:2 竖图导出 900 × 1800），两张尺寸一致，不含桌面工具与提示。两张图片都写好才发布完成的导出目录。写盘失败保留草稿，不播放成功寄出。

寄出动画结束后，自动打开本次导出文件夹（Windows 资源管理器），保留旧卡并切到新信纸。旧卡仍可用箭头找回。点击信纸右侧文件夹打开收藏册的导出根目录（也可 F）。右上 × 关闭工作台。

```text
<游戏实例>/postmark/<玩家与服务器或单人世界的上下文哈希>/
  album.json
  assets/
  exports/
    postmark-.../
      front.png
      envelope.png
```

备份时复制整个上下文目录。图片按内容哈希存储，已盖印的章面快照不随资源包变化；相同图片不会重复保存。损坏或未知版本草稿会报错并保留原文件。历史“山野”“航空”预设章已从腰包移除，但旧卡上的印迹与资源保留。

## 玩家盖章清单

内置 2026-09-10 的 TeaCon 2026 玩家表快照。按官方 UUID 匹配的展馆可提前显示章位；尚无图案时显示淡色问号章，实际发现后补图。清单不增加收藏数，也不产生检索脚印。明确只有一枚章的馆可以在领取后打勾；空白或存疑不视为无章。圆勾表示清单及已知章集齐，后来发现未领取的新章会撤销。详情标注来源日期；数据覆盖和待核对项见 [预设说明](STAMP_CATALOG.md)。
