# 操作说明

## 信纸与工具

按 P 打开明信片。可以从左侧腰包拖章到纸上松开，也可以点击取章，再点击纸面盖下。同一个章可以重复使用；已盖印迹的位置与大小固定，想调整时先擦除再盖。

持章按住右键拖动：向右或向上放大，反向缩小，范围为纸宽的 2%–50%。缩放时落点固定，松开右键仍拿着章；左键确认盖印。每次重新拿章从默认大小开始。滚轮旋转；持章停稳 500 ms 后，工具变为半透明并出现实际章面预览，此后移动、旋转仍保持，下一次拿章才重置。

盖完自动归位，纸外松开或 Esc 取消。上一枚回包时可以拿另一枚。从大袋拿章后，左侧腰包自动平滑滚动到对应格子；归位跟随真实章位。远距离滚动未完成时会延长回包动画。

点击纸张左下橡皮或按 E 拿起橡皮，点击印迹擦掉最上层。拿着橡皮时点击章，自动放回橡皮并拿章。

## 搜索章袋

点击左侧搭扣或按 Tab 展开。章面错位排列，悬停放大并显示展区名称；其他章不被挤动。滚轮平滑缩放，拖动空隙或按住右键平移。

在袋口输入展区名称，匹配章从原位置浮到前面，其余章留在暗处。名称与类型可以组合，例如 `花园 大师`；也支持 `expert`、`visitor` 及 ID，英文大小写不敏感。多个空格分隔的词需同时匹配。目前不支持拼音搜索。

只有普通章或大师章时，只显示已有的一枚；没有匹配章时提示未找到。仅凭收藏无法区分展区没有设置章与玩家尚未收集。不同展馆可以共用图片，章的身份仍独立。搜索结果很多时滚轮上下浏览。

点击结果后收袋并拿起该章，移动到纸面再点击；也可以直接拖出后松开盖印。清除文字回到章堆，右上 ×、Esc 或 Tab 收起。在同一界面内保留搜索和浏览位置。

## 集章吊牌与纪念票

左下吊牌正面显示已收集的不同章数；点击翻面，查看普通、大师、展馆数量和十孔卡。每收集十枚，解锁一张带数字的纪念票，点击拿起后放到明信片上，也可缩放、旋转和擦除。两侧小箭头切换已解锁的票。

重复盖印、启程预设章和纪念票不增加收藏数。同一展馆的不同章分别计数，展馆只计一次。孔卡目标是下一个十枚里程碑，不代表全服总数；SMU 客户端没有可信的完整可获得章目录。纪念票随本地收藏保留。

界面只保留名称、数字和短状态。把鼠标移到物件上，在屏幕最下方查看操作说明；按钮上的键名只提示可选快捷键。

## 翻页、照片与签名

- 左右淡色像素箭头或 [ / ] 切换已有卡片，点击纸上方带加号的纸张新建（也可 N）；每张卡独立保存照片、印迹和签名。
- 将 PNG/JPG 拖到界面后，点击「裁切」或「原图比例」预览确认。裁切居中填满 3:2 信纸；原图模式完整保留画面，按原比例盖章，章面保持正方形。× 或 Esc 取消导入。点击纸上方素纸控件恢复标准 3:2 信纸（也可 B）。
- 点击右下信封角，信纸装入信封并封口，随后翻面。信封与底图比例一致，竖图使用竖版信封；签名区域和寄出动画也随之调整。
- 在背面按住左键签名；每笔松开后保存。点击信封左侧回转箭头撤回上一笔、橡皮清空签名（也可 Ctrl+Z / Delete），Esc 或左下纸角返回明信片。
- 点击右下封蜡，保存后寄出。签名可以留白。

## 明信片收集册

点击加号右侧的大册子图标打开册子。左右两页各四张，一屏八张；缩略图保留原卡比例。页角箭头翻页，点击缩略图取出该卡。再次打开时定位当前卡所在的页。

每张卡旁的小垃圾桶用于删除，点击后用勾确认、× 取消。删除当前卡自动选相邻卡；最后一页删空后回到前页。删除最后一张时留下新空白信纸。删除只移除收集册草稿，已导出的本地图片、共用图像资源与印章收藏均保留。

## 导出与草稿

每次导出包含 `front.png` 和 `envelope.png`。标准/裁切模式为 1800 × 1200；原图模式长边 1800，短边按原图比例取整（如 1:2 竖图导出 900 × 1800），两张尺寸一致，不含桌面工具与提示。两张图片都写好才发布完成的导出目录。写盘失败保留草稿，不播放成功寄出。

寄出动画结束后，自动打开本次导出文件夹（Windows 资源管理器），保留旧卡并切到新信纸。旧卡仍可用箭头找回。点击信纸右侧文件夹打开收藏册的导出根目录（也可 F）。右上 × 关闭工作台。

```text
<游戏实例>/postmark/<玩家与服务器或单人世界的上下文哈希>/
  album.json
  assets/
  exports/
    postmark-.../
      front.png
      envelope.png
```

备份时复制整个上下文目录。图片按内容哈希存储，已盖印的章面快照不随资源包变化；相同图片不会重复保存。损坏或未知版本草稿会报错并保留原文件。历史“山野”“航空”预设章已从腰包移除，但旧卡上的印迹与资源保留。
