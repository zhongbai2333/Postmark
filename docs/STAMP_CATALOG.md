## 合并规则

- 玩家明确确认本次导出作为收藏目标：按 `confirmedByExport` 显示预期数量的问号剪影；仅导入章 ID，不保存导出里的 item、玩家 owned/检索/集齐状态。实际发现后显示淡色章面，领取后点亮。
- 实际发现及已领取记录按展馆 UUID + 章 ID + 图案（item）合并；实际图案替换同类别的预设剪影，同 ID 的不同图案分别保留。
- 普通 `visitor`、大师 `expert` 来自 SMU 该届标准章位。0.1.3 起，共用章位但图案不同的章分别计数；原始导出确认 112 个标准章位；0.1.4 再根据玩家提供的两处盖章台 NBT，为锻星之旅确认第二个普通章图案，合计 113 枚预期图案。新增图案继续由实地扫描补充。
- 每个标准章位均已明确且合并后的章全部实际获得，才显示圆勾。明确单普通章、无大师章的馆可以完成；大师空白本身不表示无章。实际已领取齐确认目标即可显示圆勾，无需等待范围覆盖。已加载区块扫描与传送点 X/Z ±64 格扫描继续执行；只有旧社区提示和未知馆可按完整本地结果缩减章位，确认目标中的已知章位保持，扫描到新的章则扩展目标。
- 实际发现能推翻预设的「无」，额外未领取章会撤销圆勾。所有已知章都获得后才能恢复。
- 圆勾表示玩家清单及当前已知章集齐，不能证明社区表未记录的章不存在。没有预设且尚未完成传送点范围检索的展馆，仍要求普通 + 大师 + 已发现额外章。完成范围后可按本地结果识别单章馆；未发现章时不盖集齐勾。
- 脚印只来源于完成的已加载区块盖章台扫描。

## 验证

预设专项单元测试覆盖 UUID 绑定、未绑定合并行、预设不授章/留脚印、明确单章、未知大师、预设被实际发现推翻、额外章撤销完成、同 ID 多图案独立领取、同图案重复盖章台去重及清空重收集。另有实际 SMU 合成世界中的预设问号章位、详情点击及原导览流程回归；不是正式活动服务器验收。

## 玩家实测导出

0.1.1 起支持 `/postmark export` 导出 JSON，0.1.3 起按 UUID、章 ID 与 item 区分图案，记录当前 SMU 已领取章（`server_owned`）、服务器同槽覆盖前由本地保留的已领取图案（`local_collected`）以及仅扫描发现的章（`local_discovered`）。旧存档中缺少 item、尚未完成章面匹配的记录不猜测导出。提供文件后可据此维护预设；不自动导入、不把未出现的章写成 ABSENT。`allKnownCollected` 仅表示当前已知章集齐，不能作为全服章表穷尽证明。

本次确认来源：用户提供的 `stamp-catalog-1789026592606-53911dc7.json`，导出于 2026-09-10T07:49:52Z。资源 `playerExport` 保留来源文件 SHA-256 和计数。本次将缺少的标准槽标为预期 ABSENT 是依据用户随后明确要求用这份全收集记录决定剪影数量；仍允许实际发现推翻，不能理解为服务器以后不会增加章。

## 确认的同 ID 图案

`confirmedArtworks` 可对一个已确认展馆列出 `{id,item}`，当前仅锻星之旅使用。记录时空超算 `anvilcraft:spacetime_supercomputer` 与锻星砧 `anvilcraft:celestial_forging_anvil`。两者均为 `visitor`；每个预设只产生 `item=null, asset=null, owned=false` 的独立剪影，身份中的预期 item 用于匹配实际扫描结果，不用于提前加载图案。两种章均领取后才集齐，完整范围扫描也不删除人工确认但尚未发现的章。

来源为玩家提供的同展馆 UUID 盖章台 NBT：时空超算 `(980,22,-123)`、锻星砧 `(991,34,-109)`。坐标仅记录核查来源，不作为身份，不用于额外授章。
