展馆身份依据 [Puer 官方展馆声明](https://github.com/teaconmc/Puer/blob/9993186cab48a2e41f757878b3458d08e25617cd/2026/data/exhibition_portal/galleries.json)。仅按 UUID 关联，绝不按名称模糊匹配。数据随 JAR 离线提供，不在游戏中请求腾讯文档，也没有在线自动更新。

## 覆盖

资源 `src/main/resources/assets/postmark/catalogs/teacon2026.json` 保留全部 71 条展馆/分组记录与源行号，其中 66 条绑定官方 UUID，可提前预告 101 个章位。

总表普通章：70 条「有」，1 条「无？？？？」；大师章：38 条「有」，6 条「无」，27 条空白。只有明确「无」才记为 ABSENT；空白和存疑都为 UNKNOWN。只记录章位事实与必要的共槽说明，不包含攻略正文、传送指令、截图、玩家身份或会话信息。

## 合并规则

- 预设 PRESENT 先显示未获得章位；没有真实章面时显示淡色问号实体章。
- 实际发现及已领取记录按展馆 UUID + 章 ID 覆盖预设；不修改 SMU、收藏存档或检索存档。
- 普通 `visitor`、大师 `expert` 来自 SMU 该届标准章位。铁砧工艺及其附属中共用章位的多个图案仍只计一枚。
- 每个标准章位均已明确且合并后的章全部实际获得，才显示圆勾。明确单普通章、无大师章的馆可以完成；大师空白本身不表示无章。alpha.27 起，完成传送点周边 X/Z ±64 格全部区块检索后，实际发现和已领取记录优先；仅来自预设而未被实地发现的章位会隐藏，包括 PRESENT，单普通章、单大师章对称处理。未完成范围检索仍保留预设提示；不改写原始清单或历史发现。
- 实际发现能推翻预设的「无」，额外未领取章会撤销圆勾。所有已知章都获得后才能恢复。
- 圆勾表示玩家清单及当前已知章集齐，不能证明社区表未记录的章不存在。没有预设且尚未完成传送点范围检索的展馆，仍要求普通 + 大师 + 已发现额外章。完成范围后可按本地结果识别单章馆；未发现章时不盖集齐勾。
- 脚印只来源于完成的已加载区块盖章台扫描。

## 验证

6 项预设专项单元测试覆盖 UUID 绑定、未绑定合并行、预设不授章/留脚印、明确单章、未知大师、预设被实际发现推翻、额外章撤销完成、图案替换及共槽去重。另有实际 SMU 合成世界中的预设问号章位、详情点击及原导览流程回归；不是正式活动服务器验收。

## 玩家实测导出

0.1.1 起支持 `/postmark export` 导出 JSON，按 UUID 和章 ID 记录当前 SMU 已领取章（`server_owned`）以及仅扫描发现的章（`local_discovered`）。提供文件后可据此维护预设；不自动导入、不把未出现的章写成 ABSENT。`allKnownCollected` 仅表示当前已知章集齐，不能作为全服章表穷尽证明。
