# 实现设计

## 文档与存储

`model` 保存不可变 Album、Postcard、Imprint 和签名笔画。印迹位置按纸张归一化，每次盖印获得独立 UUID；提交后不会因拖动工具而改变。擦除从最上层按逆旋转与纸张宽高比命中。

`storage` 按世界/服务器与玩家上下文隔离，图片按 SHA-256 内容寻址。草稿同目录临时写入后原子替换，成功才更新内存。导出先写齐正反两张 PNG，再发布为完成目录。旧版本缺省签名迁移为空笔画；不支持的文档版本或损坏数据保留原文件并报错。

## 渲染与交互

`PostcardPainter` 共用于界面与导出；标准正面 1800 × 1200，原图模式长边 1800，另一边按比例取整；底纹与像素纸张从基础网格放大。章面读取原图，工具外壳由 `StampToolPainter` 单独合成，不改变印迹内容。半透明作用于整件工具，避免分层叠加不透明。

`PostcardScreen` 的主要状态：持章 → 左键确认 → 120 ms 接触并保存 → 380 ms 抬起 → 回包。回包独立于交互锁，允许再拿另一枚。其目标与左侧滚动的真实章位一致，临近章位时口袋前沿遮挡章底；通常为 240 ms，远距离立即取消则延长到滚动收敛后。`SmoothShelfScroll` 用 75 ms 时间常数的帧率无关缓动。

`StampPreviewTimer` 停稳 500 ms 后锁定预览，再用 180 ms 淡入；工具不透明度 28%，实际落点章面 48%。后续移动、旋转仍保持，下一次拿章重置。预览不创建印迹也不写盘。

右键缩放固定落点，范围为纸宽 2%–50%，右键释放和缩放中左键释放不盖印。已确认盖印及回包记录各自保存尺寸。翻页用 560 ms 抽纸动画，保留旧纹理直到完成，切换期间锁住纸面编辑，防止写错卡。

## 章袋

`StampBag` 在当前工作台上展开深色衬里的袋口。章面按六角格中心错位排列并轻微固定倾斜，悬停平滑放大至 1.65 倍。命中按原格中心，邻居不移动，放大的章最后绘制。

`StampBagIndex` 按展区 UUID 稳定分组。搜索使用 NFKC、大小写归一化及多词 AND 匹配；原生 EditBox 接收字符、粘贴与预编辑事件。搜索期间屏蔽信纸快捷键。匹配章用 300 ms 从原位置浮到前面，其余保留 13% 不透明度；移动期间不误选。点击结果先持章，累计拖动超过 4 像素才按拖动释放处理。

只展示已收藏的记录，缺少某类章时不补位。图片可以共用，收藏 key 和印迹来源独立。SMU 名称更新原位替换已有 key；异步图像捕获完成时使用当前作用域的最新名称，防止回写旧标签。

## 信封与导出

纸张移动到袋口 → 滑入信封 → 折盖 → 翻面 → 鼠标签名 → 封蜡确认 → 异步导出固定文档快照 → 写盘成功 → 信封飞出 → 打开本次文件夹并新建信纸。

装信封时纸张纹理始终存在，靠前袋、左右折边和封盖逐步遮挡，不能按时间直接隐藏。签名按笔保存，撤回、清空及返回纸面不改变正面内容。写盘失败不播放成功动画、不切换新卡。

## 可选联动

`SignMeUpBridge` 通过可选 Mixin 重定向客户端编辑入口，保留服务器授章。仅在新服务端快照确认后同步地图位置；图片异步回调核对会话与连接，避免跨服务器归档。详情见 [COMPATIBILITY.md](COMPATIBILITY.md)。

## 收藏进度与提示

`CollectionProgress` 从已持久化的收藏按 key 去重，排除 practice；精确识别 visitor/expert，按展区前缀统计展馆。不推算全服总章数。`CollectionTag` 翻面展示十孔里程碑，新增收藏更新计数与轻提示音。

`MilestoneTicketPainter` 生成原创像素纪念票，通过已有图像资源和 Imprint 流程保存、擦除、缩放和导出；票不加入收藏列表，也不修改草稿格式。

`HoverHint` 统一在底部显示当前鼠标目标的说明。`DeskControls` 绘制无常驻长文字的像素操作控件，键盘快捷键与鼠标操作共享原有编辑流程。

## 自定义底图比例

`Postcard.width/height` 持久化实际画布尺寸；旧草稿缺省两个尺寸时迁移到 1800 × 1200，所有不可变编辑保留尺寸。`Imprint.contains` 按文档比例换算到纸宽单位，预览与导出中的章面保持正方形。

`PhotoImportChoice` 提供两张合成预览，确认前不修改文档，取消时释放纹理。裁切采用中心填充；原图模式保留完整画面，输出尺寸限制在长边 1800。页面过渡分别保存旧纸和新纸尺寸。

`EnvelopeLayout` 共享装封终点与翻面起点尺寸；信封角、折盖、签名面和导出跟随纸张比例。纸张保持比例缩进内袋，封盖与侧折边重叠遮挡。信封纹理按新尺寸重新绘制，标识和封蜡保持各自比例。
