# 实现设计

## 文档与存储

`model` 保存不可变 Album、Postcard、Imprint 和签名笔画。印迹位置按纸张归一化，每次盖印获得独立 UUID；提交后不会因拖动工具而改变。擦除从最上层按逆旋转与纸张宽高比命中。

`storage` 按世界/服务器与玩家上下文隔离，图片按 SHA-256 内容寻址。草稿同目录临时写入后原子替换，成功才更新内存。导出先写齐正反两张 PNG，再发布为完成目录。旧版本缺省签名迁移为空笔画；不支持的文档版本或损坏数据保留原文件并报错。

## 渲染与交互

`PostcardPainter` 共用于界面与导出；标准正面 1800 × 1200，原图模式长边 1800，另一边按比例取整；底纹与像素纸张从基础网格放大。章面读取原图，工具外壳由 `StampToolPainter` 单独合成，不改变印迹内容。半透明作用于整件工具，避免分层叠加不透明。

`PostcardScreen` 的主要状态：持章 → 左键确认 → 120 ms 接触并保存 → 380 ms 抬起 → 回包。回包独立于交互锁，允许再拿另一枚。其目标与左侧滚动的真实章位一致，临近章位时口袋前沿遮挡章底；通常为 240 ms，远距离立即取消则延长到滚动收敛后。`SmoothShelfScroll` 用 75 ms 时间常数的帧率无关缓动。

`StampPreviewTimer` 停稳 500 ms 后锁定预览，再用 180 ms 淡入；工具不透明度 28%，实际落点章面 48%。后续移动、旋转仍保持，下一次拿章重置。预览不创建印迹也不写盘。

右键缩放固定落点，范围为纸宽 2%–50%，右键释放和缩放中左键释放不盖印。已确认盖印及回包记录各自保存尺寸。翻页用 560 ms 抽纸动画，保留旧纹理直到完成，切换期间锁住纸面编辑，防止写错卡。

## 章袋

`StampBag` 在当前工作台上展开深色衬里的袋口。章面按六角格中心错位排列并轻微固定倾斜，悬停平滑放大至 1.65 倍。命中按原格中心，邻居不移动，放大的章最后绘制。

`StampBagIndex` 按展区 UUID 稳定分组。搜索使用 NFKC、大小写归一化及多词 AND 匹配；原生 EditBox 接收字符、粘贴与预编辑事件。搜索期间屏蔽信纸快捷键。匹配章用 300 ms 从原位置浮到前面，其余保留 13% 不透明度；移动期间不误选。点击结果先持章，累计拖动超过 4 像素才按拖动释放处理。

只展示已收藏的记录，缺少某类章时不补位。图片可以共用，收藏 key 和印迹来源独立。SMU 名称更新原位替换已有 key；异步图像捕获完成时使用当前作用域的最新名称，防止回写旧标签。

## 信封与导出

纸张移动到袋口 → 滑入信封 → 折盖 → 翻面 → 鼠标签名 → 封蜡确认 → 异步导出固定文档快照 → 写盘成功 → 信封飞出 → 打开本次文件夹并新建信纸。

装信封时纸张纹理始终存在，靠前袋、左右折边和封盖逐步遮挡，不能按时间直接隐藏。签名按笔保存，撤回、清空及返回纸面不改变正面内容。写盘失败不播放成功动画、不切换新卡。

## 可选联动

### 漫游志

`GuideBridge` 通过反射读取全部展馆元数据与 UUID 对应的原生馆图路径，沿用 SMU 的 `TeleportToExhibitionPacket`。未配置有效朝向的传送点不可用。馆图单击在同一目标内按下、松开才触发传送；角落印章和馆名是独立命中区域。

`GuideSurvey` 通过 NeoForge 客户端区块加载/卸载事件维护实际区块集合，每 tick 最多检查 4 个区块内的盖章台，不限制与玩家的距离。每次检查前以客户端缓存中的区块实例重新验证，跳过已卸载、替换或移出缓存范围的区块；视距缩小时即使没有卸载事件也会清理失效引用。移动不会重置进度，切换世界清空区块集合，切换会话丢弃未提交结果。不会请求或生成远处区块。

已检查盖章台的所属馆留下检索脚印；检查到玩家当前所在区块时，也可给主世界内导航点距玩家 24 格以内的最近展馆记录空检索。脚印不读取 SMU 的 visited 标记。每 20 tick 或一轮结束批量保存结果，一轮结束等待 40 tick 后重新遍历，以发现后来添加或修改的盖章台。传送只重置扫描调度，保留仍加载的区块集合。发现结果只累计、按 UUID + 章 ID 去重，不等同于完整现存章目录。

`TravelJournal` 与 `TravelJournalStore` 保存发现的章 ID/原始物品或纹理来源以及检索完成状态。它们不修改 Album 收藏，单独使用同作用域下的 `travel-journal.json` 原子保存。损坏或未知版本保留原文件并报错。已获得的章继续以现有 Album 记录为依据。

`TravelGuideScreen` 使用同一张大画布容纳所有展馆，`GuideCanvasLayout` 采用固定角度的散点布局与 UUID 决定的纸片大小、颜色、倾角，移除分栏和分页。`GuideViewport` 保存平移和缩放状态，滚轮缩放以鼠标为锚点，位移和倍率使用同一指数缓动插值，拖动超过 4 GUI 像素取消点击；视图可一键恢复全览。无记录时以可读倍率打开；退出时按玩家与服务器/世界原子保存归一化浏览中心和目标缩放，重开直接恢复，窗口大小改变后保持中心。

馆图、馆名与角章共用相机、倾角和 17% 悬停放大变换；命中反向换算到纸片坐标。悬停纸片提升绘制次序，移开平滑缩回，只绘制可见纸片。背景淡色山形、树木、水纹固定在画布坐标，拖动时不会滑动或重排。从背包进入时，右侧实体章入口打开工作台，关闭后返回同一画布。

角章复用 `StampToolPainter` 的完整木柄/金柄实体纹理，预览按普通/大师分别缓存，未获得时对整个工具统一降低透明度，避免将物品章面误读为普通物品图标。普通/大师固定两角、额外章进入详情；命中范围包含握柄与底座。有 UUID 预设时，圈勾按已明确的章位和实际已知章计算；未知槽不当作无章，明确单章可以完成。无预设仍要求普通 + 大师且已发现章均已获得。零散空检索不证明无章。集齐标识为 26 像素浅底深绿圆勾，位于馆图上方中心，与待检索问号共用位置且问号优先；完成检索后显示圆勾。馆图外缘增加两像素绿色细框，不在图片内部加遮罩。点击圆勾打开详情。猫爪、问号、圆勾预先合成一张纹理图集，每个标识每帧只提交一个纹理四边形。章预览按使用顺序最多缓存 256 张，每帧至多启动 2 个任务、同时最多 2 个待处理任务；低于 55% 仅为悬停馆和详情补充预览，其余复用已有纹理或显示柄形轮廓，离开界面释放纹理并使旧异步回调失效。

顶部问号由 `StampCatalog.needsInspection` 控制：实际已领取全部预期章时直接换成圆勾，否则没有检索记录时显示；普通/大师槽有实际发现、持有证据或清单明确 ABSENT 可消除未知。另以传送点 X/Z ±64 格覆盖的全部区块完成一次实际扫描，且提交时仍为同一个已加载区块实例，记录 `SurveyArea`；范围内未发现的旧社区清单章位可按本地估计消除；玩家确认导出清单以预期数量为准，已知目标不会因局部扫描未发现而删除；历史发现及已领取章仍保留，普通单章和大师单章对称处理。单章实际领取后可集齐，零章不盖勾，新发现未领取章撤销集齐。旧 `travel-journal.json` 缺少 area 时按未完成范围处理；记录绑定传送点 XYZ 和半径，位置变化需重新覆盖。右下猫爪印为约 36 像素浅底深色贴章，两枚爪印错开位置、角度、大小和墨色，与集齐圆勾独立；两种标识都使用纸片坐标变换命中，点击打开详情，拖动仍只平移。

`SignMeUpBridge` 通过可选 Mixin 重定向客户端编辑入口，保留服务器授章。仅在新服务端快照确认后同步地图位置；图片异步回调核对会话与连接，避免跨服务器归档。详情见 [COMPATIBILITY.md](COMPATIBILITY.md)。

## 收藏进度与提示

`CollectionProgress` 从已持久化的收藏按 key 去重，排除 practice；精确识别 visitor/expert，按展区前缀统计展馆。不推算全服总章数。`CollectionTag` 翻面展示十孔里程碑，新增收藏更新计数与轻提示音。

`MilestoneTicketPainter` 生成原创像素纪念票，通过已有图像资源和 Imprint 流程保存、擦除、缩放和导出；票不加入收藏列表，也不修改草稿格式。

`HoverHint` 统一在底部显示当前鼠标目标的说明。`DeskControls` 绘制无常驻长文字的像素操作控件，键盘快捷键与鼠标操作共享原有编辑流程。

## 自定义底图比例

`Postcard.width/height` 持久化实际画布尺寸；旧草稿缺省两个尺寸时迁移到 1800 × 1200，所有不可变编辑保留尺寸。`Imprint.contains` 按文档比例换算到纸宽单位，预览与导出中的章面保持正方形。

`PhotoImportChoice` 提供两张合成预览，确认前不修改文档，取消时释放纹理。裁切采用中心填充；原图模式保留完整画面，输出尺寸限制在长边 1800。页面过渡分别保存旧纸和新纸尺寸。

`EnvelopeLayout` 共享装封终点与翻面起点尺寸；信封角、折盖、签名面和导出跟随纸张比例。纸张保持比例缩进内袋，封盖与侧折边重叠遮挡。信封纹理按新尺寸重新绘制，标识和封蜡保持各自比例。

## 像素落印与收集册

`StampRaster` 在文档分辨率生成带透明边缘的局部印迹，虚影与最终合成都使用它。虚影按完整画布的采样相位投影，不再直接将原图在 GUI 像素中独立缩放旋转；局部纹理按坐标、大小、角度和资源缓存。`PaperViewport` 给出统一的整数显示矩形，纸面输入用同一边界换算。

`PostcardAlbumScreen` 使用每屏八张、左右各四张的册子布局。翻页期间保留相邻两屏缩略图，完成后释放离屏缓存；预览保留纸张比例。`Album.select(UUID)` 和 `remove(UUID)` 维持选中卡合法，删除最后一张时生成空白卡，印章列表保持。操作沿用 ClientSession 的原子保存；不删除共用资源或导出文件。

### 漫游志位置与渲染缓存（alpha.24）

背包入口从左键按下开始捕获整个手势，位移达到 4 GUI 像素后拖动，松开时保存相对屏幕位置；轻点松开才打开。NeoForge ScreenEvent 前置事件消费按下、拖动和释放，防止容器槽位处理同一手势。生存与创造背包共用实例级入口配置，读取失败保留原文件并回退初始位置。

每馆已知章、集齐、检索和范围状态仅在 journal、收藏章列表或展馆元数据变化时重算；绘制和命中查询复用快照。场馆布局不再每帧重建 UUID 列表。馆图资源存在性缓存随界面重新初始化刷新。装饰纹理包含贴签和四种背景图案，背景只绘制可见单元，极低倍率加大图案间距，使单元数量受屏幕尺寸约束。背景在画布裁剪区内连续平铺，不随内容边界截断。

明信片收藏册保留原始 `layout`、`slots`、外框、书脊、翻页铰点和控件。仅替换 `leaf` 的底纸填充色，并在绘制卡片前加入每页居中的 TeaCon 水印和当前玩家名；原有水印资源着浅金色并缓存为纹理，跟随书页翻转。关闭时释放水印，卡片缩略图及导出内容不变。

集齐圆勾的扫描线在未旋转的像素网格上合成，最后在 GUI 层整体旋转该纹理四边形。避免 Java2D 对各行分别旋转栅格化时产生缝隙，露出底层圆圈或阴影；每个标识仍只绘制一个四边形。

0.1.2 的玩家确认清单包含 74 个 UUID、112 个预期章位（36 个单章馆、38 个双章馆），仅导入 visitor/expert 槽位。`confirmedByExport` 区分确认目标和旧社区提示，导出中的章面资源标识、owned/searched/area/completion 状态均不导入。`display` 为已知目标生成无 item/asset 的剪影，为清单外未知馆保留两个未知剪影；真实发现或领取覆盖剪影。范围扫描持续执行，后续新章会扩展目标并在未领取时撤销勾。
