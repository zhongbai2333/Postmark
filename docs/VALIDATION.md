## 单元测试

- 不可变文档、重复印迹独立 ID、旋转擦除与纸张宽高比。
- 地图玩家中心、标记比例、边缘裁切与非法坐标。
- 草稿/资源读回、上下文隔离、损坏文件保留、路径约束。
- 1800 × 1200 PNG 合成、透明度、签名笔画、旧草稿迁移及导出失败处理。
- visitor/expert 精确识别、整枚工具透明、500 ms 预览保持。
- 小数滚轮、不同帧率缓动一致、滚动边界和远端章位平滑定位。
- 中文/多词/全角英文搜索、稳定收藏更新、4096 个蜂窝格中心无重复。
- 只有普通、只有大师、无匹配结果；不同展馆共用图片仍保留独立收藏与印迹来源。

- 收藏去重与普通/大师/其他分类、展馆去重、1–4096 枚孔卡边界、纪念票解锁。
- 纪念票像素透明背景、草稿读回与 PNG 合成，预设章和纪念票不增加收藏数。

- 原图保留上下边缘、3:2 居中裁切、横竖与方形纸张的正方形印迹和旋转擦除。
- 可变尺寸草稿保存、盖印/签名/擦除后保留比例、旧草稿缺省尺寸迁移。
- 自适应信封纹理与 900 × 1800 正反 PNG 导出、签名位置一致。

## 实际 Minecraft 工作台

模拟鼠标和键盘验证：唯一预设章、拖动或点击拿取、同章重复盖印、擦除最上层、工具归位、回包期间拿另一枚、橡皮直接切章、500 ms 预览及移动旋转保持、右键调整大小且不误盖、预览与实际印迹一致。

覆盖左右箭头和键盘翻页、旧卡内容与签名保留、纸张持续滑入信封、封盖遮挡、翻面签名、撤回/清空、返回重开、两张 PNG 导出与草稿重载。成功寄出后新建卡，并可翻回旧卡。

121 枚章夹具验证蜂窝布局、悬停放大、中文名找出普通/大师一对、多词只找大师、搜索不触发信纸快捷键、点击结果不在下方纸面误盖、累计小步拖出释放正常盖印、暗处非匹配章不可选。大袋取章与归位后对应左侧章位可见，远端取章立即取消也能返回可见格子且不盖印。

检查实际截图中的章袋、居中搭扣、搜索浮出、取章滚动、回包及信封各阶段。彩色章只用于独立测试目录，测试后恢复原草稿。

新增实际游戏验证：九枚普通章翻面显示九孔；同一展馆新增大师章后变为十孔并解锁纪念票，展馆数量保持九。点击拿票不会误盖，放到纸面后草稿与导出合成一致。鼠标点击新建、恢复素纸、打开文件夹、关闭工作台，以及签名撤回/清空全部通过；截图检查数字吊牌、纪念票与下方悬停提示。

新增底图与信封验证：导入等待鼠标选择且屏蔽下层快捷键；点击原图模式生成 1:2 竖纸，实际盖印与擦除命中符合纸张比例。竖版装封、闭合、翻面、鼠标签名和寄出成功，两张 PNG 均为 900 × 1800；自动换新卡、裁切模式、取消导入、混合比例翻页及再次打开保留内容。截图复查封盖与侧折边完整遮挡纸张。

## 像素对齐与收集册（alpha.12）

`gradlew runClient -PsmokeTest -PalignmentSmoke`：真实 GPU 分别渲染虚影和最终印迹，比较截图中的着墨轮廓，六组均为零差异。覆盖奇数界面尺寸、竖纸、宽纸、旋转、非整数章尺寸、边缘裁切。虚影的透明度不同，比较的是轮廓位置而非颜色值。

`gradlew runClient -PsmokeTest -PbookSmoke`：19 张不同纸型夹具分为三屏；检查左右各四张、翻页和末屏三张。取消删除保留卡片，连续删空末屏自动回前屏；缩略图打开目标卡，再打开定位所在页。删除当前卡选相邻卡，删除最后一张留下新空白卡，草稿持久化且章收藏不变。人工检查收集册与翻页截图。

单元测试补充删除后文档合法性、收藏保持、UUID 选择、存储读回，以及不同窗口/纸型下输入与显示像素边界一致。

## 真实 SMU

使用上游提交 `32dcde5fd52e8b4805196b1fcf9bb2e121b64028`、ExhibitionPortal 1.1.12，创建新测试世界并通过正常 `useItemOn` 与真实盖章台交互。

确认客户端 Mixin、生效后的 Postmark 界面、服务器授章、新快照等待、地图位置及尺寸回传和服务端保存。原玩家标记下目标约 20.5 GUI 像素；测试地图背景比例刻意不同于世界范围。

确认 grass_block 原生三维模型、paper 平面物品和直接 PNG 捕获；GUI 2 时物品快照 32 像素，保持透明度。服务端 visitor/expert 使用相同章面而握柄不同，读取草稿后仍能识别。

服务端展区名“联动花园”进入本地普通/大师章标签；仅改名为“更新花园”后，两枚已收藏的名称更新并持久化，图片保持一致。

## 尚未覆盖

用户的远程活动服务器及其专用资源包、所有第三方特殊物品渲染器与输入法候选窗尚未逐项人工验证。字符输入使用原生 EditBox；模糊效果受游戏菜单背景模糊设置影响。CI 执行构建与单元测试，图形和集成服务器测试需按开发说明单独运行。

alpha.11 首轮完整游戏回归通过。最终封盖遮挡调整使用 `-PsmokeTest -PphotoSmoke` 单独复核；随后两次完整复测在章袋悬停处因桌面焦点丢失（鼠标坐标 0,0）中断，因此不把那些运行记为通过。

alpha.12 完整游戏回归最终通过，另有六组 GPU 像素轮廓零差异与收集册专项通过。中途一次章袋数量失败来自先前异常退出残留的 alignment 测试章，已将夹具初始化限定为唯一预设章后重跑。右上角加大入口另行复测点击与实际截图。

alpha.13 将收集册移到加号右侧，保留图标大小与点击范围；复用收集册专项验证实际入口点击、打开、翻页与删除，并检查入口截图。构建与 28 项单元测试通过。
